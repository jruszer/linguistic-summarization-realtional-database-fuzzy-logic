# Agregacja Lingwistyczna Danych ATP Tour (2015-2020)

## Opis Projektu
Celem zadania jest stworzenie aplikacji w technologii Java (JDK LTS), której główną funkcjonalnością jest lingwistyczna agregacja zawartości zbioru danych dotyczącego meczów tenisa rozgrywanych podczas ATP Tour w latach 2015–2020. 

Zbiór danych obejmuje:
- **12 046 rekordów**
- **14 atrybutów** opisujących mecze

Aplikacja generuje i analizuje podsumowania lingwistyczne (wykorzystując 10 zmiennych lingwistycznych), których podmiotem jest pojedynczy mecz. Analiza wyników skupia się na określeniu znaczenia wybranych kwantyfikatorów, sumaryzatorów, kwalifikatorów oraz miar ich jakości dla wiarygodności otrzymanych podsumowań.

## Przykład Podsumowania
> „Niewiele meczy jest wygranych przez zawodnika spoza top 100 i liczba asów to około 20. [0.82]”

## Technologie
* **Język:** Java (wersja LTS)

# Linguistic Aggregation of ATP Tour Data (2015-2020)

## Project Overview
The objective of this project is to develop a Java application (JDK LTS) focused on the linguistic aggregation of a dataset containing ATP Tour tennis matches played between 2015 and 2020.

The dataset includes:
- **12,046 records**
- **14 attributes** per match

The application generates and analyzes sample linguistic summaries (using 10 linguistic variables) where the subject is a "match". The analysis of the results involves determining the significance of selected quantifiers, summarizers, qualifiers, and their quality measures for the credibility and quality of the generated linguistic summaries.

## Example Summary
> "Niewiele meczy jest wygranych przez zawodnika spoza top 100 i liczba asów to około 20. [0.82]”

## Technologies
* **Language:** Java (LTS version)
